# VERA STUDIO — tienda virtual

Este directorio es el proyecto independiente del catálogo web VERA STUDIO.

- Sitio estático HTML, CSS y JavaScript.
- WhatsApp para consultas.
- Categorías: dama, hombre e infantil.
- Productos en `products.js`.

Para publicar como sitio independiente en GitHub Pages, se recomienda crear un repositorio público dedicado llamado `vera-studio` y subir allí el contenido de esta carpeta a la raíz. No habilitar Pages en el repositorio de Bienestar Contigo para este catálogo.
